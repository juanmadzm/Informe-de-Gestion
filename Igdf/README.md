# Informe de Gestión y Legado 2025-2026

Sitio estático. Publicar en Vercel:

1. Descarga el proyecto y súbelo a un repositorio de GitHub (o arrastra la carpeta en vercel.com/new).
2. En Vercel: New Project → importar el repo.
3. Framework Preset: **Other**. Build Command: vacío. Output Directory: vacío (raíz).
4. Deploy.

Archivos necesarios: index.html, support.js, doc-page.js, assets/, vercel.json.
El visitante puede imprimir o guardar como PDF con Ctrl/Cmd+P.
